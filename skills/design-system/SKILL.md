# Skill: design system

Use this when choosing color, type, spacing, components, or motion.

## Source of truth

`design/DESIGN_SYSTEM.md`.

## Do

- Use the Adire indigo palette (`indigo-ink`, `indigo-dye`, `resist-white`, spare `cassava-gold`).
- Fraunces for display, Figtree for body, IBM Plex Mono for IDs.
- Result, upload, map, passport, and chat components should match the written specs.
- Use `genuine` / `print` / `uncertain` colors only for real verdicts. The stub stays `uncertain`.
- Motion is short and respectful; honor reduced-motion.

## Don’t

- Don’t style the product like a government certificate or a fake authenticity seal.
- Don’t shame “factory print” with alarmist red.
- Don’t add decorative batik patterns that bury the photo or the reasons.
